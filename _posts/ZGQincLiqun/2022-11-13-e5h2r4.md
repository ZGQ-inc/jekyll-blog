自从昔日大名鼎鼎的“白嫖界”云服务巨头 [Heroku](https://www.heroku.com/) 正式宣布彻底取消其祖传的完全免费基础计划之后，全球无数的白嫖党、开源作者、以及练手项目的学生开发者瞬间失去了部署小型应用和 Telegram 机器人的绝佳阵地。

为了拯救那些被迫连夜搬家的流浪项目，这里为大家推荐一个 GitHub 上的宝藏开源聚合项目。

### ☁️ Heroku Free Alternatives (Heroku 免费替代品大全)

这是一个专门收集和整理目前市面上**依然提供长期免费额度 (Free Tier)** 的海外云计算平台、PaaS (平台即服务) 以及数据库服务的开源列表库。

**✨ 列表包含的白嫖资源类别：**
* 🌐 **PaaS 计算平台：** 能够直接完美替代 Heroku，支持一键连接 GitHub 部署代码和 Web 应用的免费全托管计算平台。
* 🗄️ **云原生数据库托管：** 各种依然提供慷慨免费托管额度的关系型和非关系型数据库服务（涵盖 PostgreSQL, MySQL, MongoDB, Redis 等）。
* ⚙️ **BaaS / Serverless 架构：** 免费的后端即服务及 Serverless 无服务器云函数平台等。
