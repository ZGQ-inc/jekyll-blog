### 🆚 一、Flexbooru：老牌强大的全能选手

Flexbooru 是一个极其老牌且硬核的开源 booru 画廊客户端。它除了提供强大的基础画廊浏览功能外，还可以作为 Android 著名的 Muzei 壁纸的直接来源，并原生内置了极具价值的“以图搜图 / 以图搜番”高级引擎。

**✨ 核心优势功能：**
* 🎨 **UI 风格：** 搭载 Material Design 3（拥有白 / 黑 / 纯黑夜间模式，且支持动态模糊）。
* 瀑布流样式的绝佳沉浸浏览界面。
* 支持**云端收藏**与媒体原图下载。
* 支持自行添加或深度修改 booru 站点配置，且完美**支持备份站点配置**。
* 支持全局屏蔽特定的 Tags 标签，以及一键屏蔽隐藏所有的 NSFW (不安全内容) 进入安全模式。
* **高级访问权限：** 完美支持配置 API key / 账号密码。**这对于访问那些需要登录验证或传入 Token 才可以浏览的高限制级敏感媒体和本子来说是必须的！**

**⚠️ 客观缺点与限制：**
* 添加新图源时比较繁琐，不支持自动扫描 booru 站点配置。
* 浏览界面的瀑布流不支持针对 NSFW 缩略图内容进行自动模糊化（容易社死）。
* **目前部分核心代码未完全开源。**

> [!CAUTION]
> **频道主温馨避坑提示 (极其重要)：**
> 该软件的开发者在最新版中已经开始“恰饭”了，各种离谱的付费功能自始至终都没有进行过开源。因此频道极力推荐大家停留在**最后的纯净旧版本**。在以前的纯净旧版中，你可以**完全免费**使用以下极其珍贵的付费功能：
> 1. 无可用的 booru 站点数量限制
> 2. 可以直接从本地文件批量备份和恢复 booru 站点配置
> 3. 无限制使用 SauceNao 强大的以图搜图服务

* **下载获取：** [前往 GitHub 查看与下载 (请自行寻找旧版发布页)](https://github.com/flexbooru/flexbooru)
* **支持的引擎：** Danbooru 1.x & 2.x, Moebooru, Gelbooru 0.2.x, Shimmie 2.x 等。
* **开源许可证：** `GPLv3`

**💾 Flexbooru 专属站点配置导入包：**
* [15 个官方 booru 画廊站点配置参考](https://flexbooru.github.io/flexbooru/config.html)
* **频道主打包的配置文件 (直接批量导入)：** [点击下载 16个图源合集 JSON 配置文件](https://github.com/ZGQ-inc/source/releases/download/16/boorus_16.json)

### 🆚 二、Boorusphere：基于 Flutter 的现代新秀

Boorusphere 是一个使用现代跨平台框架 Flutter 编写的全新开源 booru 画廊客户端，拥有极其丝滑跟手的动画与交互体验。

**✨ 核心优势功能：**
* 🎨 **UI 风格：** 同样采用极其美观的 Material Design 3（白 / 黑 / 纯黑 且支持模糊）。
* 支持本地收藏与文件下载。
* **极简智能扫描：** 支持自动扫描并解析 booru 站点配置（傻瓜式操作，只需要输入基础 URL 网址即可自动匹配图源规则）。
* 支持自行添加/修改 booru 站点，支持全局屏蔽特定 Tags 以及直接屏蔽 NSFW 内容。
* **极致的隐私防社死：** 它的浏览界面**完美支持对各种 NSFW 限制级内容进行高强度的全局高斯模糊化处理**（开会、坐地铁时刷图的防社死神器！）。

**⚠️ 客观缺点与限制：**
* 极其纯粹的本地化，目前竟然不支持备份和恢复用户数据。
* **最大的遗憾短板：** 完全不支持配置 API key 和账号密码，因此它彻底无缘访问那些需要登录账号或传入 Token 才可以解锁浏览的那些高限制级媒体和极品本子。

* **下载获取：** [前往 IzzyOnDroid (F-Droid 第三方软件源) 查看与下载](https://apt.izzysoft.de/fdroid/index/apk/io.chaldeaprjkt.boorusphere)
* **支持的引擎：** Danbooru, Gelbooru, Konachan, Safebooru, Yandere。
* **开源许可证：** `BSD-3-Clause`
