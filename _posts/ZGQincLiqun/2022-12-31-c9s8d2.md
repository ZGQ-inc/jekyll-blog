最近在极客圈内看到了下面这个危险的网站，貌似是一个专门针对 Telegram 用户隐私数据的在线黑产社工库。

### ☠️ Telegram 隐私查询社工库

* **网站入口：** [https://cybersec.org/en/tg](https://cybersec.org/en/tg)

**📢 频道主辣评与原理解析：**
很多非技术圈的小白认为 Telegram 主打“端到端加密”所以在这上面干嘛都是绝对安全的，其实这是个极大的误区。TG 的确是可以被“社工”的，因为无论它的前端端到端数据传输多么无懈可击，存放在官方服务器后端的账号关系数据库依然有被“脱裤 (拖库)”泄露的潜在可能。

之前圈内知名的“红鼻子”等机器人，可以通过用户名反向查询出某位用户加入了哪些公开群组（这主要靠的是在海量公开群组里提前安插监控机器人爬取沉淀数据）。但这回这个网站**竟然能直接查出底层绑定的注册手机号**，这就有点离谱了。

目前也不知道是不是 TG 的某个早期的边缘节点分发库真的被脱了，还是黑客团伙单纯使用大量的已知黑产手机号，通过 TG 的添加联系人接口去自动批量化跑字典碰撞匹配出来的。我个人估计只有极少量的早期信息被定向泄露，并没有像隔壁国内某 Q 那种骇人听闻的“祖传 16 亿全量裤子泄露”。**经初步验证，目前这些被泄露手机号的数据似乎绝大多数只有俄罗斯地区的用户，其它地区目前暂未发现大规模集中泄露。**

### 💻 接口调用与查询结果解析

该社工库甚至猖狂地开放了非常直白的 API 请求接口供人自动化调用：
* **API 请求格式：** `https://cybersec.org/en/tg/?tgid=[这里替换为目标用户全数字ID]`

**查询结果返回值的 JSON 参数含义解释：**
```json
[
  {
    "TelegramID": "用户的全数字底座 ID",
    "FirstName": "（昵称）姓氏",
    "LastName": "（昵称）名",
    "Name": "可能是泄漏的真实姓名",
    "Nik": "设置的 @ 用户名 (Username)",
    "Email": "账号绑定的邮箱 (若有)",
    "Phone": "极其致命的注册绑定手机号码"
  }
]
```
