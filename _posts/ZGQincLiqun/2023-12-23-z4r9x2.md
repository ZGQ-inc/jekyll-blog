本期带来一款安卓端极其硬核的极客底层终端利器。

如果你是深度的 Linux 爱好者或移动端极客，那你绝对听说过甚至折腾过大名鼎鼎的安卓底层终端模拟器原版 [Termux](https://termux.dev/cn/)。而今天分享的这款工具，则是基于它打造的超级“保姆级”魔改版。

### 💻 ZeroTermux (本地终端增强版)

* **项目开源与全量获取地址：** [👉 点击前往 GitHub 查看 ZeroTermux](https://github.com/hanxinhao000/ZeroTermux)

ZeroTermux 是原版 Termux 的一个极其出色的国内 Fork 衍生分支，由国人大佬倾力定制开发。相比于原版极客但门槛极高、纯粹干瘪的命令行环境，它在底层直接集成了海量对国内小白极其友好的开箱即用自动化脚本。

> [!WARNING]
> **安装冲突排雷警告：**
> 由于基础包名和组件签名环境的物理冲突，在安装使用 ZeroTermux 之前，你**必须彻底卸载手机上原有的原版 Termux**，否则将无法安装或导致 Linux 子系统运行环境彻底崩溃。

### 🚀 频道主专属的实用功能把玩向导

为了方便极客新手们快速上手，频道主特意整理了几个 ZeroTermux 最核心也是最能装逼的内置快捷功能（其核心交互呼出方式均为 **“双击屏幕最左侧边缘”** 以唤出左侧抽屉快捷菜单）：

* 📦 **一键无痛换源：** `双击屏幕最左` -> 选择 `切换源` -> 列表里直接傻瓜式勾选国内的 `清华源 (TUNA)` 等镜像，彻底告别原版半天拉不下来库的龟速折磨。
* 🐧 **Linux on ARM (容器极速装系统)：** `双击屏幕最左` -> 选择 `MOE全能`。
  你可以在这个极其逆天的菜单里，通过底层 proot 容器极其方便地“一键安装”各种你想要的 Linux 完整发行版子系统（类似[此前的折腾文章介绍](https://t.me/ZGQincLiqun/2593)）。对于初次接触 Linux 命令行的萌新小白，强烈建议优先选择极其成熟的 `Ubuntu`。
* 🍷 **体验 Wine (在手机上强跑 EXE)：** `双击屏幕最左` -> 找到 `QEMU` -> 选择 `海的QEMU` -> 选 `6`。
  *(注：这里的内置环境仅限极客尝鲜体验“在安卓上运行 Windows `.exe` 桌面程序”，底层算力转换极其粗糙简陋，绝对不建议当做日常重度使用。如果真想在手机上流畅跑 PC 的 EXE 黄油游戏或大型软件，频道主**强烈推荐**你去使用目前移动端体验最好的原生专用 PC 模拟器 👉 [Winlator 项目](https://github.com/brunodev85/winlator)。)*
* 🪟 **一键注入 Linux 高仿 Windows 主题：** 
  同上述体验 Wine 的操作步骤，在你进入并安装完子系统后，在弹出的 `wine_menu` 选项里可以直接选择安装一整套 Windows 主题皮肤 *(参考：[频道附属群内的实机效果图](https://t.me/LiqunZGQinc/275771))*。
  *(💡 **硬核知识点科普：** 这个极其逼真的伪装主题组件，其实在底层适用于大部分主流的 Linux 发行版，它的设计初衷可见著名的极客防社死隐蔽模式 👉 [Kali Undercover](https://www.kali.org/docs/introduction/kali-undercover/))*。
