对于广大的 Minecraft (我的世界) 硬核玩家来说，HMCL 绝对是 PC 端最知名、也是最好用的第三方启动器之一。今天为大家强烈推荐它的官方 Android 移动端移植版本。

### 🧊 HMCL-PE (官方安卓版启动器)

HMCL-PE 是专门适用于 Android 设备的 Minecraft Java 版启动器。它的底层十分硬核，不仅继承了大名鼎鼎的 [PC 原版 HMCL](https://github.com/huanghongxun/HMCL) 拥有的几乎所有强大功能，还能让你在手机和平板上获得极其完整的 Java 原生态游戏体验！

**✨ 核心硬核功能：**
* 🎮 **全版本制霸：** 支持直接在移动安卓设备上原生运行 Minecraft Java 版本的几乎所有历史大版本。
* 🧩 **主流模组框架：** 完美支持一键自动化安装第三方极客核心框架（如：`Forge`、`OptiFine`、`Fabric` 等）。
* ☕ **内置 Java 环境：** 原生自带支持底层翻译运行的 `Java 8` 和 `Java 17` 运行库环境。
* 🚀 **双核驱动引擎：** 启动器底层支持直接接入 [Boat](https://github.com/AOF-Dev/Boat) 和 [PojavLauncher](https://github.com/PojavLauncherTeam/PojavLauncher) 两大顶级运行引擎。
* 🌐 **账号与联机：** 完美支持配置本地离线账号与微软 Xbox 在线正版账号登录；支持局域网多人联机游玩。
* 📦 **资源全托管：** 支持一键在线下载源文件，以及本地深度管理 Mod (模组)、光影纹理包、游戏存档世界和大型懒人整合包。
* 🕹️ **虚拟手柄映射：** 专门针对触屏设备优化，支持创建、深度修改并分享高度自定义的虚拟控制器操作键位布局。
* 🎨 **高颜值 UI：** 继承了 PC 端的优良传统，拥有可高度定制的现代化启动器 UI 主题和全局颜色。
