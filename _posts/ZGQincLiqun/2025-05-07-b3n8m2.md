对于拥有三星手机的极客而言，其原生生态矩阵 (如多屏协同、三星笔记、Quick Share 等) 极其好用，但极其恶心的是，**三星官方在 Windows 客户端底层物理锁死了机型验证，必须是三星自家的 Galaxy Book 系列电脑才能被允许安装和运行！**

今天，频道主将教你如何利用开源极客脚本，在系统底层直接伪装硬件标识特征码，强行绕过这种极其流氓的机型白名单。让你在**任何第三方组装机或普通笔记本**上，也能完美体验最新的 One UI 7 全家桶。

### 🚀 全新解封方案 (One UI 7 完美适配版)

> [!TIP]
> **底层弃用提示：** 以前那些极其繁琐的 `SamsungSystemSupportEngine` 本地补丁脱壳与手动安装伪装驱动的老方案**现已全面废弃**。
> 以下全新的解封方案将全部交由底层环境脚本进行自动化物理挂载，即刻享受 One UI 7 的最新生态红利。

#### 1. 物理环境前置要求：安装 PowerShell 7 预览版
新的底层欺骗脚本高度依赖 `PowerShell 7.x (Preview)` 的最新架构运行。
* **📥 微软商店极速直取：** [PowerShell 预览版](https://apps.microsoft.com/detail/9P95ZZKTNRN4)

#### 2. 强行挂载环境劫持脚本 (GalaxyBookEnabler)
* **项目仓库：** [github.com/Bananz0/GalaxyBookEnabler](https://github.com/Bananz0/GalaxyBookEnabler)

直接在系统环境中以最高管理员权限唤起刚刚安装的 PowerShell 7 预览版，输入以下降维打击指令进行底层注入与部署：
```powershell
saps pwsh-preview -Verb RunAs -Args "-nop -c irm https://raw.githubusercontent.com/Bananz0/GalaxyBookEnabler/main/Install-GalaxyBookEnabler.ps1|iex"
```

#### 3. (可选) 全域应用强制拉取
如果你的应用商店被物理锁区，或者想强行安装所有的三星专属应用（甚至包括那些已经被官方物理废弃隐藏的旧版组件），请执行以下全量部署脚本：
```powershell
saps powershell "-c irm https://gbee.zgqinc.gq/InstallAllSamsungApps.ps1|iex" -Verb RunAs
```

* **📋 全部三星应用名录检索：** [👉 点击查看支持列表](https://github.com/ZGQ-inc/GalaxyBookEnablerEnhanced?tab=readme-ov-file#三星应用程序列表)

### 🧹 遗留污染清理与物理回退

> [!CAUTION]
> **底层驱动死锁警告：**
> 如果你以前曾跟着频道旧贴的教程，手动在系统里注入过那个极其复古的 `SamSysSupSvc` 伪装驱动。**在执行本次新方案前，你必须先使用清理脚本，将系统的历史遗留污染强行物理剥离！** 否则新旧两套劫持系统会在 Windows 内核极其恶劣地打架，从而导致全局死锁。

* **🚨 强行回退与清理旧版残留的终端清理指令：**
  ```powershell
  irm https://gbee.zgqinc.gq/restore.ps1 | iex
  ```
清理完毕后，再按上文执行全新的 `GalaxyBookEnabler` 注入流程。（*切记，不管怎样，别自作聪明把新的 `GalaxyBookEnabler` 给卸载了，那个后台欺骗锚点是刚需！*）

### 🏛️ (已废弃) 旧世代底层驱动劫持方案存档

*(注：以下老旧的本地脱壳与虚拟驱动打补丁方案已被废弃，现在 7.0 的底层验证更加变态。旧方案仅作为逆向工程代码参考予以保留！)*

* **底层伪装脱壳文件提取：** `SSSS_6.3.3.0` / `SSSS_7.0.10.0`
* **部署底层逻辑：** 曾经极其繁琐，需要将破译版的 `SamsungSystemSupportService.exe` 强行塞入 C 盘根目录。
* **虚拟设备强行挂载驱动：** 必须在设备管理器的 `其他设备` (如 `CONTINUITY_MSG_SPP` 或是 `Flow`) 节点中，强行右键物理打上本地解包出的虚假证书驱动。
* **底层系统服务提权创建：**
  ```cmd
  sc create "SamsungSystemSupportEngine Service" binPath= "C:\SamSysSupSvc\SamsungSystemSupportService.exe" start=auto
  ```
* **历史开源参考点：** [SamsungSystemSupportEngine-Patched](https://github.com/BlueOutside/SamsungSystemSupportEngine-Patched) | [GalaxyBookEnabler v2.0 遗迹](https://github.com/rushiranpise/GalaxyBookEnabler/tree/v2.0)
