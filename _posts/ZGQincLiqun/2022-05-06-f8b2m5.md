这一系列由开源开发者 `niuhuan` 主导的第三方二次元及漫画客户端合集，绝大多数均支持 **全平台 (Android / iOS / MacOS / Windows / Linux)** 覆盖，且无广告、体验优秀。

### 各平台独立客户端

* **哔咔漫画 第三方客户端 (niuhuan/pikapika)**
  * **简介：**(R18+) 美观易用且无广告的二次元客户端，同时支持 MacOS, Windows, Android, iOS。
  * **仓库：** [https://github.com/niuhuan/pikapika](https://github.com/niuhuan/pikapika)

* **禁漫天堂 第三方客户端 (niuhuan/jasmine)**
  * **简介：**(R18+) 一个美观易用的漫画客户端，同时支持 Android / iOS / MacOS / Windows。
  * **仓库：** [https://github.com/niuhuan/jasmine](https://github.com/niuhuan/jasmine)

* **动漫之家 第三方客户端 (niuhuan/daisy)**
  * **简介：**(R12+) 美观易用且无广告的二次元客户端，免费的漫画和轻小说资源，并已上传 APK 和 IPA。(基于 Rust+Flutter)
  * **仓库：** [https://github.com/niuhuan/daisy](https://github.com/niuhuan/daisy)

* **Konachan 第三方客户端 (niuhuan/coco)**
  * **简介：**(R18+/R12+) A illustrations and wallpapers client. (插画与壁纸客户端)
  * **仓库：** [https://github.com/niuhuan/coco](https://github.com/niuhuan/coco)

* **Nhentai 第三方客户端 (niuhuan/nhentai-cross)**
  * **简介：**(R18+) 美观易用且无广告的 nhentai 漫画客户端，**重点功能是可以免代理直连使用**。
  * **仓库：** [https://github.com/niuhuan/nhentai-cross](https://github.com/niuhuan/nhentai-cross)

* **Hitomi.la 第三方客户端 (niuhuan/html-comic)**
  * **简介：** A hitomi.la client. 一个 Hitomi.la 客户端。
  * **仓库：** [https://github.com/niuhuan/html-comic](https://github.com/niuhuan/html-comic)

* **Pixiv 第三方客户端 (niuhuan/pansy)**
  * **简介：**(R18+/R12+) Illustration client. 一个插画客户端。
  * **仓库：** [https://github.com/niuhuan/pansy](https://github.com/niuhuan/pansy)

### 终极聚合版客户端

* **禁漫 / 哔咔 / Nhentai / Pixiv 聚合客户端 (niuhuan/glxx)**
  * **简介：**(R18+) 绅士集结，包含前述四大图源聚合的大一统客户端。
  * **仓库：** [https://github.com/niuhuan/glxx](https://github.com/niuhuan/glxx)
