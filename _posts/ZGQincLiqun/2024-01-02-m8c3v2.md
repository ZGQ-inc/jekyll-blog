Steam 官方客户端的默认 GUI 界面实在是太古老厚重了，如果你早就看腻了那套万年不变的深色布局，那就利用这款极其硬核的开源客户端修补神器来彻底改造它吧！

**✨ 核心注射器：SFP (原 SteamFriendsPatcher)**

这是一款专门为强行修改并自定义 Steam 客户端 UI 构建的开源内存修补工具。通过劫持和替换底层的 CSS 与 GUI 文件，它能让你的 Steam 瞬间脱胎换骨。
* **获取地址：** [👉 前往 GitHub 获取 SFP 本体包](https://github.com/PhantomGamers/SFP/)

### 🎨 极品现代主题生态推荐

装好 SFP 后，你可以尽情在社区里寻找并应用大神们编写的 CSS UI 主题包。以下是频道主精选出来的几款绝对能让你眼前一亮的顶级主题：

* 💎 **[Fluently](https://github.com/Hexality/Fluenty)**：极度奢华的现代化 Fluent 亚克力流体毛玻璃质感，完全融入 Win11 的设计语言。
* 🖤 **[Zehn](https://github.com/yurisuika/Zehn)**：暗黑系极简美学，去除一切多余的线条和渐变，极客最爱的纯平风格。
* 🔲 **[Metro](https://github.com/RoseTheFlower/MetroSteam)**：经典、硬朗且永远不过时的 Metro 扁平化磁贴交互设计。
* 💾 **[Win95](https://github.com/2641a40fd44383320adde4b027a1d0b03bd550/steam-win95-skin)**：返璞归真的终极整活赛博考古，带你一秒穿越回 1995 年的灰白立体系统时代。
