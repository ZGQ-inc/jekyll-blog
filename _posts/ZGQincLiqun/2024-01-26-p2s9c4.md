本期推荐一款能让重度音乐发烧友和数据统计控狂喜的极客移动端应用。

### 🎵 Pano Scrobbler (歌曲信息与个性化分析伴侣)

* **开源获取地址：** [👉 前往 GitHub 查看 Pano Scrobbler 源码与下载包](https://github.com/kawaiiDango/pano-scrobbler)
* **开源许可证：** `GPLv3`

Pano Scrobbler 的核心愿景非常浪漫但又极其硬核：“忠实记录你这辈子所听过的一切”。
它不仅仅是一个在后台默默记录你播放状态的跟踪器，它更是目前极其知名的音乐记录生态圈社区 `Last.fm`、`Libre.fm` 以及 [ListenBrainz](https://listenbrainz.org/) 非常优秀的第三方聚合客户端。

**✨ 核心特色功能盘点：**
* **全局底座捕获：** 能够无差别接管并记录你安卓设备上几乎“所有”音乐播放器的实时播放历史。
* **数据可视化大屏：** 深度分析你长期的听歌曲风与喜好，并能自动生成极其炫酷的统计图表，甚至能在每周或每月结束时自动生成你的专属“曲风词云”。
* **极致的信息获取：** 支持通知栏快捷音乐伴侣模块、以及极具沉浸感的弹出式歌曲信息弹窗；支持直接查看极度硬核的歌曲详细元数据（包含极其精准的小众曲风分类）。
* **社区与黑名单管理：** 支持极其暴力的全局歌曲/艺术家拉黑隔离名单，支持编辑你的自定义高阶用户标签，甚至还能“偷窥”查看好友的听歌统计数据。
* **听歌识曲：** 内置接入了极其强悍的第三方底层听歌识曲服务。
* **数据本地化：** 支持一键导入和导出你的所有精调设置以及庞大且珍贵的音乐历史列表。

---

### 🟢 极佳的 Spotify 进阶辅助伴侣

如果你是全球流媒体巨头 Spotify 的重度用户，那么 Pano Scrobbler 绝对是你必须要装的辅助“外挂”神器。

众所周知，Last.fm 社区与 Spotify 的底层 API 配合得极其完美。你只需要在后台通过简单的 [连接授权 Spotify 账号](https://www.last.fm/zh/settings/applications)，Pano Scrobbler 就能接管并无缝记录你在 Spotify 上所有的播放历史残影数据，并根据这些全量数据，为你生成极其硬核且全面的私人音乐品味解剖报告。

> [!NOTE]
> **开发者打赏与功能说明补充：**
> 该软件的基础开源核心功能其实已经足够强大，但为了支持开源开发者继续用爱发电，其内部仍有极小部分诸如 UI 深度定制等非刚需的高级功能需要进行微小捐赠后方可解锁使用，故以上盘点并未全数列出。
