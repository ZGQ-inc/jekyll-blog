想要在手机上跑完整的 Linux 系统但又苦于没有底层的 Root 挂载权限？又或者是看到那些部署教程里密密麻麻繁琐枯燥的黑框框命令行直接被劝退？

今天推荐的这款名为 **Tiny Computer** 的极客工具，绝对是你在安卓移动设备上折腾 Linux 桌面系统门槛最低、交互最舒服的“神仙级傻瓜式 GUI 懒人包”。

### 🐧 Tiny Computer

* **GitHub 开源库与下载：** [https://github.com/Cateners/tiny_computer](https://github.com/Cateners/tiny_computer)

这是一款通过底层 `proot` 容器技术，全自动为你在一台**完全没有 Root 的普通安卓手机上**，从零开始直接拉起并部署一个原生 ARM 架构的完整 Linux 系统的应用。它甚至连底层桌面环境和 VNC 画面显示服务都直接在后台给你全自动包办了，附带了极其装逼的黑客伪装皮 `Kali Undercover`。

**极客点评与避坑配置建议：**
* **桌面环境选择：** 安装时软件提供了 `xfce` 和 `lxqt` 两种主流的轻量级 Linux 桌面环境可供选择。博主个人极其强烈建议无脑选择 **xfce**，无论是系统的稳定度、中文组件的兼容性，还是在极小屏幕下的触屏手势交互逻辑，都远远好于后者。
* **变态级的内嵌快捷指令集：** 它的牛逼之处在于，直接在安卓 APP 的系统交互 UI 层里，内嵌了涵盖几乎所有本来极其折腾人的高阶底层配置指令。你可以直接点击面板按钮一键傻瓜式执行：
  * **一键无缝开启内置 VNC 显示与底层 Tmoe 管理脚本**
  * **底层系统软件源一键强行替换为清华源 (极其重要，防龟速甚至断流报错)**
  * **一键跨架构支持：部署 `Box86` / `Box64` 翻译层指令集**
  * **一键跨系统支持：部署原生 `Wine` 环境 (意味着你可以在手机的 Linux 环境里直接运行 Windows 的 `.exe` 程序！)**
  * **一键 `DXVK` (DirectX 硬件图形加速转换底层支持)**
  * **开启 `Virgl GPU` 硬件级 3D 物理渲染加速**
  * **手机宿主机物理文件系统映射穿透**
  * 修复 C 语言底层编译环境报错缺失、修复中文系统编码支持、开启垃圾回收站... 甚至还有隐藏的拉流测试与神秘彩蛋指令。

> [!WARNING]
> **关于体积膨胀与作者恰饭的吐槽：**
> 虽然它名字叫“Tiny (微小的)”，但如果你是个重度折腾狂，把你上面看到的那一堆高级的底层扩展库（如 Wine, Box86 和桌面环境生态）全都一股脑装进手机里，它在宿主手机上的实际物理存储占用轻轻松松就能突破 **5GB** 的大关，只能说这体积一点都不 Tiny！
> 
> 另外提醒一下，这虽然是个极其优秀的 GitHub 开源外壳打包项目，但为了恰饭，作者在应用内部植入了广告接口。上述列表里提到的一些极度硬核的高级指令功能，是需要你在客户端里看一次广告才能解锁永久执行权限的。
