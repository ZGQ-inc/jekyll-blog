其实每个人都可以免费申请 Cloudflare 的 ZeroTrust 服务，它的 Free 免费套餐可以提供给 50 个人使用（即 50 个邮箱账户）。今天就简单跟大伙说一下申请方法。

### 🛠️ Cloudflare ZeroTrust 免费申请教程

1.  **注册与登录：** 首先进入 Cloudflare Dashboard 注册或登录账号：[dash.cloudflare.com](https://dash.cloudflare.com/)
2.  **进入 ZeroTrust：** 接着进入 ZeroTrust 管理页面：[one.dash.cloudflare.com](https://one.dash.cloudflare.com/)
3.  **选择套餐：** 在侧边栏找到 `Access` -> `Applications`，你会看到 `Get started with Cloudflare Zero Trust` 栏目。点击 `Choose a plan`，选择 **Free 套餐**，然后点击 `Proceed to payment`。
4.  **绑卡验证：** 这一步会要求填写支付方式，**必须要有一张外币信用卡**。点击 `Add payment method` 填好信息，返回后点击 `Next`。系统会自动生成一张免费的订单，到这里就申请成功了。
5.  **配置组织：** 申请成功后，在侧边栏点击 `Settings` -> `General`，在 `Team domain` 一栏起一个属于你自己的组织名称。
6.  **设置验证邮箱：** 在侧边栏点击 `My Team` -> `Devices` 设置验证邮箱。虽然 ZeroTrust 界面上让你限定邮箱域名，但后来我们发现填入其它普通域名也是可以正常登录的。

**如何使用？**
下载并打开 `1.1.1.1` 客户端，在设置里的账户选项卡中，点击 `登录到 Cloudflare Zero Trust`，输入你刚才配置的组织名称（Team domain）加入组织，之后就可以快乐享受无限流量了。

> **科普：什么是 Cloudflare Zero Trust？**
> 这是一个安全平台，能让你更快、更安全地连接互联网和应用。设备注册后，你可以体验更安全的浏览、自动防御恶意软件，而且无需传统 VPN 就能随时随地访问网络。
