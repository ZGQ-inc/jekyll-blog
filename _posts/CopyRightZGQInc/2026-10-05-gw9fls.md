手里的设备都淘汰了，之前提到过：我的 S22 Ultra 不会获得 OneUI 8.5 更新。

原因很简单，因为 OneUI 8.5 基于 Android 16 QPR2，属于一次大更新，而 2022 年的机型，包括 Fold4 和 Flip4，已经完成了 4 次更新周期，OneUI 8.0 将会是终章。其实 S22 系列之前被发现了 Android 16 QPR2 的测试固件，但是在 4 月份莫名停止了更新。

当时调侃 Fold8 挤牙膏就果断买 Fold7 了。

结果 Fold8 真挤牙膏了，所以买了 Fold7，港版 16+1TB 只要 1 万。然后之后看到 Watch4 也淘汰了，那我想我的 Watch5 Pro 也差不多了，干脆全换了。

然后再一琢磨，之前做汉化的时候抹字修图用的鼠标，很不好控制，修的时候那叫一个青筋暴起啊，所以干脆再来个平板，用过第二块屏幕功能都知道平板当副屏有多爽，还支持 S Pen 压感。不过三星大刀部发力扬了 S Pen 的蓝牙功能，无奈选 2 年前的，反正也是挤牙膏。耳机就算了，Buds3 Pro 很好，Buds4 Pro 和新品耳夹式 Buds On 的设计我不太喜欢。

### ⚠️ 刷机包格式转换：自写脚本解决 lz4 与 PIT 报错

这里需要注意了：自从 18 年开始，三星把老刷机包的 tar 压缩算法换成了 lz4+tar 混合。由于 NetOdin 自打 15 年之后就没改过，还没有支持 lz4。之前的刷机包都是三星内部员工泄露的，他们帮你转换成了 tar，现在从官方服务器获取就不一样了。试过第三方刷机工具，都不太稳定，还是官方泄露的 NetOdin 最稳，所以我写了个脚本把 lz4 重新打包成 tar，另外参考了 XDA 用户的额外操作（[XDA 原帖参考](https://xdaforums.com/t/firmware-of-samsung-galaxy-watch-7-40mm-sm-l300.4687411/post-90439285){: .preview }）。

脚本支持 Linux 和 Windows，会自动解开包里的镜像、把所有 `.lz4` 还原成 tar、剔除导致 NetOdin 报错的 `meta-data` 目录，并额外生成一份去除了 PIT 分区表防死锁的 CSC。

#### 使用方法：
先装一下 lz4 依赖：
```bash
pip install lz4
```
把脚本放到和刷机包 zip 同一目录下，运行脚本：
```bash
python netodin_convert.py
```
跑完就会生成一个 `..._NetOdin_Ready` 目录，里面的包就能直接用 NetOdin 刷了。

### ⌚ 手表无线刷机详细步骤

#### 1. 电量与准备
刷机包准备好后，**手表需要充电至少 50% 以上**。因为无线刷机的速度只有 3MB/s，别看包才 6GB 不到，实际上需要耗费半小时，刷到一半没电会导致假砖（不用担心，重新操作就好了）。

另外，三星手表元件密度比较大，无线刷机会让表体发热严重导致掉速，**建议拿出夏天刚刚结束你打算放起来吃灰的小风扇对着吹**。

#### 2. 进入 Download Mode 与识别新旧 Bootloader
进入 download mode，注意按键在右侧在这里才是正面。开机和关机状态都行：
1. **按住手表的两个按键**（Ultra 型号的 Action 橙色按键不要管）；
2. 十几秒后，屏幕上会出现白色的 **`Rebooting`**：

![屏幕出现白色 Rebooting 字样](/assets/images/2026-10/samsung_watch_rebooting_screen.jpg)
*图：出现 Rebooting 界面*

3. **这个时候赶紧连击上键**，就会进入 reboot mode 菜单：

![Reboot Mode 菜单界面](/assets/images/2026-10/samsung_watch_reboot_mode_menu.jpg)
*图：进入底层 REBOOT MODE 菜单*

任意按键单击选择，长按确认。

刚刚提到三星修改了 bootloader 的 UI：
* **Watch6 和之前**叫 `Download (Wireless)`；
* **Watch7 和之后**叫 `Wireless Download`。
* 顺带一提，老版本的 `Rebooting` 上面有个 Samsung logo，通过这个方式也能区分新旧 bl。

#### 3. 切换 AP 模式
选中 `Wireless Download` 长按进去之后，**按 2 下上键切换到 AP 模式**：

![切换到 AP 模式等待连接](/assets/images/2026-10/samsung_watch_wireless_download_ap_mode.jpg)
*图：屏幕显示 [AP] SM-L350-xxxx 与 Connect Waiting..*

#### 4. 电脑连热点与防止 Windows 自动切网
电脑连上这个手表发射的热点。

注意：Windows 连上“无 internet”的无线网络时，会在后台默默轮询合适的网络并自动切换，容易导致刷到一半突然切回你的路由器导致刷机失败。

所以连上手表热点后，需要打开 PowerShell，临时阻止后台轮询：
```powershell
netsh wlan set autoconfig enabled=no interface="WLAN"
```
*(刷完把 enabled 改成 yes 就行)*

#### 5. NetOdin 开始刷机
打开 NetOdin，塞入 BL、AP、CSC，点 **Start**。

手表屏幕看到 **`Downloading!!`** 就开始刷机了：

![表盘显示 Downloading 与进度条](/assets/images/2026-10/samsung_watch_wireless_downloading_progress.jpg)
*图：开始下发，屏幕出现进度条*

整个过程耗时半小时，结束后会自动重启，完成。刷完记得在 PowerShell 里把 Wi-Fi 轮询改回来：
```powershell
netsh wlan set autoconfig enabled=yes interface="WLAN"
```

### 🩺 假砖、关机与 PIT 报错排查

1. **如果发生意外假砖了**：会导致 boot loop。不用担心，只要在当前状态长按两个按键十几秒，屏幕出现 `Rebooting` 赶紧连击上键，就能重新进入 reboot mode 菜单，重新选 `Wireless Download` 再刷一遍就行。
2. **如果你突然不想刷了想退出 download mode**：这个时候想关机等以后再说的话，就在 download mode 界面长按 2 个按键，一样的操作，连击进入 reboot mode 菜单，里面就有 **`4. Power Off`**，长按即可关机。
3. **PIT 分区报错（RQT Write Fail）**：另外还有个问题就是 NetOdin 会莫名其妙去使用 PIT 文件也就是分区表，重新分区在未解锁 bl 的机器上是无法操作的。如果碰到了 `RQT Write Fail` 报错，需要长按上键重新引导进 download mode，**选用脚本生成的 NoPIT 的 CSC 包（`CSC_..._NoPIT.tar`）**，就能顺利刷过去了。
