**需求痛点：**
我有两个三星账号（一个国区一个加拿大区），现在想把国区账号用了几年的三星浏览器书签和历史数据，迁移到新的加拿大账号里。
结果我惊恐地发现：不同地区的三星账号，**浏览器书签竟然是无法互相同步的**！而且更离谱的是，三星浏览器自身根本不提供直接导出 HTML 书签文件的功能。
去网页版三星云申请下载个人隐私数据包，下载回来的竟然是充满了 `******` 星号乱码的 CSV 废文件，极其抽象。

**硬核终极解决办法 (需 Root 权限)：**
实在没办法，只能开大招了。
利用我那台已经 Root 了的 Note10+ 5G，先登录旧账号将数据同步到本地设备（需配合 Knox Patch）。因为三星浏览器底层和 Chrome 一样，也是用 SQLite 数据库来存储的。

1.  打开带有 Root 授权的文件管理器（如 MT 管理器）。
2.  进入系统绝密数据路径：`/data/user/0/com.sec.android.app.sbrowser`
3.  找到并强行拷贝出以下几个核心数据库文件：
    *   `databases/SBrowser.db` (主数据库)
    *   `databases/SyncMetaInfo.db`
    *   `databases/quickaccess.db` (快速访问书签)
    *   `files/readinglist` (稍后阅读列表)

这几个文件里面的数据全是未加密的明文！虽然裸看比较费劲，但只要用 Python 配合 `sqlite3` 库写个转换脚本，连接数据库遍历一下表结构，就能完美把它们转换导出成通用的 HTML 列表文件了。问题解决。
