🔗 **[官方公告源](https://t.me/durov/343)**

由于遭到滥用，Telegram 官方极为良心且无限制的极简发文平台 `telegra.ph` 已经永久关闭了本地上传图片功能。不过好在经过我测试，媒体**外部直链引用的功能 (img src)** 依然被保留了下来：
*   [外链图片测试](https://telegra.ph/img-test-09-06) | [外链视频测试](https://telegra.ph/video-test-09-06-2)

那么怎么找到稳定快速的平替方案呢？**当然是自己建一个图床呗。**

**免费零成本自建图床方案思路：**
这里提供一种极致稳定且白嫖的方法，核心思想是：利用 GitHub 仓库作为后端存储。
🔗 [GitHub 图床部署工具项目指路](https://t.me/ZGQincLiqun/1316)

该项目现在已经支持自定义外链格式了。我个人的终极极客玩法思路是：
1.  使用 **Cloudflare Pages** 绑定并拉取你的这个 Github 图片存储仓库的代码。
2.  这样你就顺带白嫖挂载了 Cloudflare 的全球顶级 CDN 边缘加速网络。
3.  在 Cloudflare 后台给它绑定一个你自己注册购买的炫酷二级域名。
4.  大功告成！（当然，嫌麻烦的话，直接使用 jsdelivr 等公共 CDN 提供的免费加速域名也没有任何问题，同样稳如泰山。）
