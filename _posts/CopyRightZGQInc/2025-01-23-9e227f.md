之前一直很喜欢用 GitHub 官方做的那个 `GitHub Skyline`（输入账号就能把一整年的代码绿点贡献图，渲染成极度优美的 3D 城市天际线建筑群）。
结果由于微软的恶心操作，这个好端端的网页端在去年被下线了，魔改成了不知所云的 `gh-skyline`。

因为我还是觉得初代原版最优雅好看，所以干脆拿前端的 3D 图形库 `Three.js` 配合 STL Loader，自己看着旧页面的缓存，强行手搓复刻了一个 Web 端出来。

*(由于个人前端渲染功底有限，水面反光材质调得感觉还是不太像官方的原版，而且目前暂未写 CSS 媒体查询去适配手机竖屏比例，建议在电脑端打开观赏。)*
