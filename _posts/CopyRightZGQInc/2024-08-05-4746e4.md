经过一晚上的折腾，已成功在 **One UI 6.0** 系统的手机上，强行激活了被官方隐藏的 `Smart View` 开发者选项和 `Second Screen` (电脑无线副屏) 功能！

![Smart View 隐藏界面](/assets/images/2024-08/photo_70@19-08-2026_22-12-44.jpg)
![Second Screen 界面](/assets/images/2024-08/photo_71@19-08-2026_22-12-44.jpg)

**前情提要与原理解析：**
众所周知，三星的 Second Screen (将设备作为 Windows 的无线显示扩展屏) 一直以来都是只给平板设备开放的。在老版本的 `Smart View` 里，我们只需要连击版本号，就能呼出隐藏的开发者选项并强开 Screen Screen。
但自从 Smart View 更新到 `8.2.21.26` 版本之后，三星封杀了这个后门，点版本号没用了。但我逆向包名发现，这个开发者活动项其实还在，只是前端入口被屏蔽了。

最开始，我尝试用常规的 ADB 无线调试启动活动项，但因为权限级别不够，直接报 `Permission Denial` 错误，这意味着必须要有完整的 Root 权限运行以下命令才能强开：
`am start -n com.samsung.android.smartmirroring/.settings.DeveloperOptionActivity`

---

### 免 Root 强开的两种进阶方案：

**方法一：利用 LockStar 锁屏快捷方式漏洞（已失效/繁琐）**
这算是个系统的权限校验漏洞。关闭锁屏定制插件 `LockStar`，用 ADB 强行把活动项注入到锁屏快捷方式里：
`settings put system lock_application_shortcut '1;com.samsung.android.smartmirroring/com.samsung.android.smartmirroring.settings.DeveloperOptionActivity;1;null;'`
然后在锁屏界面滑动图标强开。*(此方法过于繁琐，不推荐)*

**方法二：利用播放器活动项降维打击 (强烈推荐，免 Root！)**
我继续挖掘包名，找到了一个不需要底层特权就能直接调用的子活动项：`.player.SecondScreenPlayer`。

1.  手机安装 **Shizuku** 并激活（通过无线调试即可免 Root 激活 Shizuku）。
2.  安装 **Root Activity Launcher**。
3.  在软件里授权 Shizuku 权限。
4.  点击搜索按钮，勾选 `Search Components`，搜索 `SecondScreenPlayer`。
5.  展开 `Activities` 列表，找到对应的活动项，点击右侧的“发送到桌面”按钮创建桌面快捷方式。

![Root Activity Launcher 截图 1](/assets/images/2024-08/photo_72@19-08-2026_22-12-44.jpg)
![Root Activity Launcher 截图 2](/assets/images/2024-08/photo_73@19-08-2026_22-12-44.jpg)

**使用方法：** 每次想把手机当电脑副屏时，直接点击桌面的这个快捷方式，屏幕会黑屏一下，连按 2 次返回键，就能完美唤出隐藏的 Smart Screen 副屏连接界面了！
