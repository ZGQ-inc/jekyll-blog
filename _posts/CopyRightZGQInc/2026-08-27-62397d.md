顺便把这个自研的 Steam 清单抓取与入库工具整理发布到 GitHub 仓库了。以后的全部功能更新和修复都会直接在仓库维护，频道这里就不单独刷更新日志了。

🔗 **GitHub 开源仓库**：[https://github.com/ZGQ-inc/SteamManifestGrabber](https://github.com/ZGQ-inc/SteamManifestGrabber)

---

### 📖 项目背景与研发初衷

以往社区常用的第三方 Go 语言提取工具由于 SteamUI 底层网络通讯协议的调整，已彻底报错失效且年久失修。

**Steam Manifest Grabber** 基于活跃维护的 [SteamKit2](https://github.com/SteamRE/SteamKit) 底层协议库与魔改版 [DepotDownloader](https://github.com/ZGQ-inc/DepotDownloader) 底座全新自研。无需在后台开启笨重的 Steam 官方客户端，即可直连 Steam 官方服务器获取游戏清单以及通常被加密隐藏的 `DecryptionKey (解密密钥)`，并由 Python 脚本实现全自动格式化归档与 Steamtools `.lua` 规则生成。

---

### ✨ 核心特性

* 🚀 **完全脱离 Steam 客户端**：免客户端挂载，直连 Steam 官方 API 与 CDN 服务器。
* 🔑 **强行捕获解密密钥**：截获并输出 Valve 官方加密限制的 `DecryptionKey`，自动合并汇总至 `DecryptionKey.json`。
* 📜 **一键生成 Steamtools Lua**：自动为每个 AppID 生成包含主程序、加密 Depot、无清单 DLC 等完整规则的 `<appid>.lua` 入库配置文件。
* 🌐 **Steam Store DLC 自动探测**：自动调用 Steam API 检索名下拥有的全部 DLC，将无清单 DLC 自动补全至 Lua 配置中（支持 Cookies 穿透锁区限制）。
* 📦 **断点续传与批量处理**：支持通过 `task.txt` 批量流水线抓取，`progress.json` 自动记录完成进度，中断后无缝跳过已完成项。
* 🛡️ **异常容错与智能重试**：
  * 支持 Steam Guard 动态令牌输入；
  * 连接超时自动重试 3 次，并在挂起时支持人工决策 `[R]重试 / [S]跳过 / [E]退出`；
  * 遇到会话过期（`RELOGIN`）自动唤起重新登录并无缝继续当前任务；
  * 遇 `RateLimitExceeded` 速率限制时自动告警并优雅退出，保护账号安全。
* ⚡ **零第三方 Python 依赖**：Python 端 100% 基于内置标准库开发，**无需 `pip install` 任何第三方包**，解压即用。

### 🚀 快速上手

1. 安装运行环境：[.NET 9.0 桌面运行时](https://dotnet.microsoft.com/zh-cn/download/dotnet/9.0) 与 Python 3.8+；
2. 克隆仓库并运行：
   ```bash
   git clone https://github.com/ZGQ-inc/SteamManifestGrabber.git
   cd SteamManifestGrabber
   python main.py
   ```
3. 根据交互提示输入 Steam 账号凭据与目标 AppID，即可全自动完成清单下载、密钥解密、DLC 检索与 Lua 规则生成。
