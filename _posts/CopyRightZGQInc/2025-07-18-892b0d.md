**造轮子：Steam 清单底层入库提取工具发布。**

**开发起因：**
之前我在群里分享给大家用的那个由毛子用 Go 语言写的提取小工具，最近因为 Steam 官方修改了底层网络协议，彻底报错失效了。而且那个极其傲慢的开发者在 Github 上直接宣布摆烂不修了。
求人不如求己，我干脆自己抽出时间，拿 `C#` 和 `Python` 混合双打，重新从零重构捏了一个更好用的出来。

**技术底层逻辑与优势：**
*   **C# 负责突破前线**：基于著名的开源库 `DepotDownloader` 的源码进行了魔改。核心贡献在于，我让输出的控制台流可以强行截获并展示被 Valve 官方加密死死的 `DecryptionKey (解密密钥)`。
*   **Python 负责清扫战场**：写了个极其高效的自动化脚本，专门用来格式化清洗、归档那些抓取下来的杂乱清单数据。
*   **最大的压倒性优势**：相比之前那个烂尾的 Go 语言版本，我这个自研脚本**完全不需要你在后台开启笨重的 Steam 官方客户端！**
    由于我底层直接调用了社区极其成熟且积极维护的 `SteamKit2` 网络通信库，你只需要在控制台黑框里输入一次账号密码和令牌登录，后续就可以直接通过缓存跳过客户端，直接与 V 社的底层数据库建立极其高效的高速连接并疯狂抓取数据。

**跨平台编译与运行库警告：**
我把编译好的源码交叉打包成了支持 `Windows (x64 / arm64)` 和 `Linux (x64 / arm / arm64)` 的全平台二进制文件。
*(注意：为了节省上传体积，下方提供的压缩包里面只包含了最常用的 Windows x64 二进制文件，而且为了极限压缩，**我没有在里面打包微软臃肿的 `.NET 9` 底层运行库**！运行报错的请自己去微软官网下载运行库。需要其他架构平台二进制包的，去 [🔗 DepotDownloader 的 Github Releases 页](https://github.com/ZGQ-inc/DepotDownloader/releases/tag/init) 自己替换进我的壳子里即可。)*

> ⚠️ **唯一需要注意的痛点：**
> 出于安全性考虑，账号登录成功后生成的 `.session` 身份验证密钥缓存文件，是严格按照你当前的【脚本运行绝对路径】进行硬编码绑定的。这就意味着，如果你把这个文件夹整个剪切移动到了别的盘符或者目录下，你的凭证就会瞬间失效，必须重新走一遍输入密码的痛苦登录流程。

我目前只拿手里有限的设备测试了 Windows x64 和 Linux x64 环境。如果有报错抓取失败的，请在评论区带上错误日志反馈。
