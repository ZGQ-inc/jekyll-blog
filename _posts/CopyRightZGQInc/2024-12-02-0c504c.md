被国行三星内置的那个残废且充满广告的“百度圈选搜图”折磨疯了？
教你如何免 Root，完美唤醒底层隐藏的原汁原味 **Google 即圈即搜 (Circle to Search)**。

---

### 方法一：极简 ADB 暴力修改法（强烈推荐）

经过圈内大佬挖掘提醒，原来三星国行系统里一直藏着一个底层的开关控制着即圈即搜的内核归属。我们只需要用 ADB 修改一个布尔值就能瞬间切换回谷歌！
1. 手机上安装 `Shizuku` 并激活。
2. 安装 `aShell You` 这类手机端 ADB 终端应用。
3. 复制并在终端里运行这行神级命令：
   ```bash
   settings put secure cn_support_circe_to_search 1
   ```
*(如果你想重新用回百度，把结尾的 1 改成 0 重新运行即可。)*
*(注：三星的程序员极其离谱，把底层键值的单词给拼错了，是 `circe` 而不是 `circle`，大家复制的时候别以为写错了去乱改单词。此外，该键值漏洞疑似在最新的 One UI 8.0 测试版系统中已被三星堵死。)*

### 方法二：利用 MiCTS 中转劫持法（备用方案）

如果你是较新系统的受害者，ADB 失效了，可以使用复杂一点的事件劫持法。

1. 去 GitHub 下载安装核心中转软件：[parallelcc/MiCTS](https://github.com/parallelcc/MiCTS)
2. 打开手机系统设置 -> 搜索 `默认数字助理应用` -> 强制选定为 `Google`。
3. 打开系统设置 -> 搜索并开启 `即圈即搜` 功能（两种唤醒方式任选）。
4. 下载我做好的 `日常程序 (Routines)` 配置导入包：

5. 打开系统自带的 `日常程序+ (Routines+)` 插件，导入该 `.json` 文件并保存启用。

**底层劫持原理：**
MiCTS 的原理是通过调用 VIS（Voice Interaction Service）的系统开放 API 来呼出谷歌界面。
我们在导入的“日常程序”里设定了一个无声监控宏：一旦系统监测到国行的百度圈搜活动项（`com.samsung.android.bixbytouch/.activity.ShowCPCardsActivity`）被长按手势触发启动，日常程序就会在 0.1 秒内强制杀死它的进程，并瞬间替换启动 MiCTS 的活动项（`com.parallelc.micts/.ui.activity.MainActivity`），从而实现了瞒天过海的替换。
