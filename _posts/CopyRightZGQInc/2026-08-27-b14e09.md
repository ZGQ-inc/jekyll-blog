---

### 🛠️ 工具核心特性与技术实现

本项目基于 **Playwright** 移动端环境仿真与多引擎数据捕获技术，专为个人导出与备份拼多多全量消费历史而设计：

1. **会话持久化与免密复用**：
   * 自动启动移动端仿真窗口，支持手机验证码交互式登录；
   * 使用持久化 Profile (`pdd_profile/`) 模式保存 Cookie 与设备指纹，后续运行免去重复登录。
2. **多引擎全量订单捕获**：
   * 结合页面首屏服务端渲染（SSR）数据提取与自动平滑滚动网络 API 拦截，确保从最新订单至账号历史第一单 100% 完整抓取；
   * **实时增量落盘**：边抓取边同步写入磁盘主文件，中途若意外中断或手动关闭，当前已导出的数据完好无损；
   * **全量字段覆盖**：包含订单编号、订单类型（普通订单/多多买菜）、商品名称、规格、单价、数量、总金额、状态、店铺名称、下单时间及商品购买直达链接；
   * **多格式输出**：支持一键导出为 Excel (`.xlsx`)、CSV (`.csv`) 与 JSON (`.json`)。
3. **收藏与关注导出支持**：
   * 支持商品收藏（含在售、已售罄、已下架、失效商品标记）与店铺关注导出为双 Sheet 汇总 Excel。

### 🚀 快速使用

```bash
# 安装依赖
pip install -r requirements.txt
playwright install chromium

# 运行主控制台
python main.py
```
> Windows 用户亦可直接双击根目录下的 `run.bat` 一键启动。
