### 📖 DatingDarkkita-i18n 工具链简介

为了方便社区玩家进行多语言汉化与文本校对，顺便写了一套专门针对 ***Dating Darkkita 1.0***（基于 Ren'Py 8 引擎）的高自动化本地化框架与翻译构建工具链，现已完整开源在 GitHub。

支持从游戏提取文本、生成标准翻译模板、一键编译 `.rpyc` 字节码，以及跨平台打包分发。涵盖 **Windows**、**Linux**、**macOS** 与 **Android (APK)**。

#### 💡 Ren'Py 跨平台架构说明

Ren'Py 引擎的脚本底层基于平台无关的字节码（`.rpyc`）和脚本（`.rpy`）：

*   **PC 端全平台通用**：Windows 和 Linux 的游戏数据文件是 100% 完全相同的！
*   **轻量补丁打包**：制作通用补丁时仅生成轻量级的通用汉化包（约 27 MB，已内置 Google Noto Sans 思源黑体中文字体与全部翻译文件）。玩家只需解压覆盖到游戏目录即可直接畅玩。
*   **Android APK 专属重打包**：因为 Android 平台无法方便地手动拖放游戏目录，工具链提供了 APK 自动重打包、4 字节 `zipalign` 对齐与 v1/v2/v3 签名自动化流程。

### ⚡ Windows 快速上手（数字脚本）

如果你在 Windows 环境下使用，仓库预置了开箱即用的自动化批处理脚本，按数字顺序双击即可：

1.  `1_unpack_game.bat`：调用 `unrpa` 解包官方 `.rpa` 资源，并导出基础英文模板。
2.  `2_export_template.bat`：重新生成 `languages/template.json`。
3.  `3_build_all_translations.bat`：将 `languages/` 下的 JSON 翻译编译为游戏内使用的 `.rpyc` 字节码。
4.  `4_package_patch.bat`：打包 Windows / Linux / macOS / JoiPlay 通用的轻量汉化补丁压缩包（`.zip`）。
5.  `5_patch_android_apk.bat`：将汉化与字体直接注入 Android `.apk` 并完成重签名。
6.  `0_check_status.bat`：实时查看翻译进度统计表格。

### 🛠️ CLI 命令行操作参考

除了双击脚本外，还可以直接通过命令行调用 `toolkit.py`：

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 解包游戏并导出简体中文模板
python toolkit.py unpack
python toolkit.py export schinese --display-name "简体中文"

# 3. 编译翻译
python toolkit.py build schinese

# 4. 一键打包通用补丁
python toolkit.py package-patch

# 5. 注入 Android APK 并签名
python toolkit.py patch-apk
```

| 命令 | 参数 | 作用说明 |
| :--- | :--- | :--- |
| `unpack` | `[-i INPUT] [-o OUTPUT] [--all]` | 解包游戏 `.rpa` 或 `.apk` 并导出模板 |
| `export` | `<language> [-i INPUT] [-o OUTPUT] [-n NAME]` | 导出对话与 UI 字符串至 `languages/<lang>.json` |
| `build` | `<language> [-i INPUT] [-o OUTPUT]` | 构建指定语言至 `game/tl/<lang>/` 并编译字节码 |
| `build-all` | `[-i INPUT_DIR] [-o OUTPUT_DIR]` | 一键编译 `languages/` 下的所有语言 |
| `package-patch` | `[-i INPUT_DIR] [-o OUTPUT]` | 打包 Win / Linux / Mac 通用轻量补丁包 (`.zip`) |
| `patch-apk` | `[-i INPUT_APK] [-o OUTPUT_APK]` | 注入汉化至 APK 并完成对齐与签名（需 Android SDK Build-Tools） |
| `package-all` | `[-i INPUT_DIR] [-o OUTPUT_DIR]` | 一键打包通用补丁与安卓 APK |
| `status` | `[-i INPUT_DIR]` | 打印当前多语言翻译完成度统计 |
