终于等到了！

**Samsung Notes (三星笔记) 在最新的电脑端 One UI 6 大版本更新（版本号 `4.3.418.0`）中，官方终于彻底移除了那个极其恶心的品牌机型硬件校验墙限制！**

以前如果你的电脑不是高贵的“三星 Galaxy Book”牌笔记本，去微软商店下载三星笔记后，打开直接会弹出“此设备不支持”的锁死提示，逼得我们这帮极客只能去 Github 上找类似 🔗 [`GalaxyBookEnablerEnhanced`](https://github.com/ZGQ-inc/GalaxyBookEnablerEnhanced?tab=readme-ov-file#%E4%B8%89%E6%98%9F%E5%BA%94%E7%94%A8%E7%A8%8B%E5%BA%8F%E5%88%97%E8%A1%A8) 这种底层的伪装脚本来强行欺骗系统内核绕开检测。
现在，任何品牌的 Windows 电脑，无论是台式机还是组装机，都可以直接在 Microsoft Store 微软商店里无痛下载、直接双击打开并完美使用了！
完全保留了全血的跨设备云同步生态功能（只需去安装一个官方的 `Samsung Account` 组件登录账号即可自动完成无缝接力同步）。
