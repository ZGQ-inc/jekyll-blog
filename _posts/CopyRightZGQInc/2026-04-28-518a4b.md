我算是阅本无数，喜欢的本子都会下载。之前老是有朋友让我给他推荐一些，我一直是命令行 `ls` 直接甩个极其粗糙的文件夹列表给他，就很不直观。所以我自己手搓了个个人收藏集浏览器。
（注：不是每个人都喜欢这些标签内容，不喜欢可以绕道）。

🔗 **访问地址**：`https://eh.zgqinc.gq/`

那个带有数据库图标的链接是数据库工具脚本，支持 `SXJ` 版本的 EhViewer 数据库导出并抓取元数据。
**极客操作方法**：先在侧边栏 -> 设置 -> 高级 -> 导出数据，和脚本放在一个目录，运行脚本可以把 db 里面的下载列表格式化成 json，然后通过官方 API 抓取元数据和极其清晰的缩略图。

支持读取 URL 参数进行查询，非常方便展示，比如：
`https://eh.zgqinc.gq/?sort=rating_desc&cat=Doujinshi&lang=chinese&f=tag%3A%3A%3Amale%3Ayaoi%3Aor%7Ctag%3A%3A%3Amale%3Amales+only%3Aor`

另外里面如果你有喜欢的本子，但没有中文翻译的，可以在评论区极其热情地请求翻译。
主要是亲友向内容，不太想被路人看到，想了一下还是发出来算了，还特地在半夜发。
