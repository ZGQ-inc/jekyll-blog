## 🕹️ 产品一：VRChat 7点全身追踪 + 头显眼追嘴追 + 磁吸快充基站套装

市面上的全身追踪（如官方 Vive 追踪器、SlimeVR）要么价格高昂动辄几千元，要么就是远古技术。我的目标是**用千元以内的物料成本，打造一套集“7点骨骼追踪 + 头显眼追嘴追 + 超大电量无线基站 + 磁吸快充坞”于一体的下一代偏商业解决方案**。

整套硬件系统包含四大核心子系统，总物料成本仅 **¥917.52**：

### 1. 7点独立全身追踪器 (Tracker × 7 - 合计 ¥476.49)
*   **主控核心**：采用低功耗高性能的 `ESP32-C3 SuperMini`；
*   **九轴姿态融合**：`LSM6DS3` 六轴陀螺仪加速度计 + `QMC5883L` 三轴磁力计，实现高刷新率、低延迟且有效抑制零漂的姿态捕捉；
*   **独立电量与状态显示**：每个追踪节点均配备独立的**拨轮编码器与小型 OLED 显示屏**，可实时直观查看节点编号、配对状态与精确电量；
*   **电源管理系统**：`103450` 2000mAh 聚合物锂电池 + `MAX17043` 专用库仑计 IC + `INA226` 高精度电流电压采样芯片，杜绝粗暴的电压估算电量，实现工业级电量监控。

### 2. 集中式智能中枢基站 (Base Station - 合计 ¥136.22)
*   **主控芯片**：`ESP32-C6 N8`（原生支持 Wi-Fi 6、Thread、Zigbee 与 BLE 5.3），作为多节点集中接收与低延迟数据转发枢纽；
*   **超强续航中枢**：内置 4 节 `亿纬锂能 INR21700-50SE`（总容量高达 **20,000mAh / 74Wh**），可连续为基站自身供电并作为移动充能站；
*   **大功率充放电**：集成 `100W` 数显充放电一体模块 + 3 路 `5V 3A` 独立降压输出 + `INA3221` 三路电流监控 + TFT 旋钮交互中控屏。

### 3. PogoPin 强磁吸快速充电坞 (Charging Station - 合计 ¥149.12)
*   **架构设计**：`PD 100W` 诱骗 DC 供电输入 + `CD74HC4067` 16 通道多路复用芯片；
*   **安全保护**：全路集成**理想二极管单向阀（防反灌防倒灌）**与每路独立的 `PPTC 30V 1.6A` 自恢复保险丝；
*   **触点结构**：多组 4 脚 / 2 脚强磁吸 `Pogo Pin` 镀金弹簧顶针，7 个 Tracker 玩累了随手一放即可自动磁吸对准秒充。

### 4. 头显面部表情与眼动追踪套件 (Face & Eye Tracking - 合计 ¥155.69)
*   **主控与视觉处理**：`ESP32-S3 CAM (N16R8)` 高性能双核主控（支持 AI 视觉与图像流高速传输）；
*   **嘴部形态捕捉**：`OV2640` 160° 超广角近红外镜头 + `850nm` 红外补光灯板 + 特制近红外光学滤光片，无惧暗光环境；
*   **眼动与距离感知**：双通道 `APDS-9960` 光学传感器 + `TCA9548A` I2C 多路复用器；
*   **辅助系统**：配备独立 `18650` 电池、`MAX17043` 库仑计与状态 OLED 屏。

## 🔬 产品二：便携式 14 通道多光谱环境综合测量仪

面向极客、创客与科研爱好者的掌上型多功能光学与环境实验室测量终端。通过多传感器深度融合，整机物料成本仅 **¥168.55**：

### 核心硬件配置与传感器矩阵
1. **多光谱核心传感器**：`GY-AS7343` 14 通道高精度可见光与近红外光谱探测器（覆盖 14 个光学特征谱段）；
2. **光学准直聚光模组**：定制高透光率**平凸透镜**（直径 10mm / 焦距 12mm）+ 直径 4.5mm **光学柔光片**，精确约束测量光锥与受光均匀度；
3. **环境与物理测距辅助**：
   * `TOF400C (VL53L1X)` 飞行时间激光测距模块（实现毫米级测距，用于根据测量距离动态校准光谱强度）；
   * `LTR390` 宽量程紫外线 (UV Index) 与高灵敏度环境光传感器；
   * `AHT20 + BMP280` 高精度温湿度与大气压强传感器（用于环境参数监测与传感器温漂自动补偿）。
4. **主控与交互系统**：
   * `ESP32-C3 SuperMini`（支持 BLE / Wi-Fi 无线数据透传）；
   * `2.4寸 TFT` 高清彩色显示屏 + `EC11` 旋转编码器旋钮（支持波形图、色度图与光谱曲线本地实时渲染）；
   * `103450` 2000mAh 锂电池 + `MAX17043` 库仑计精准计量。

目前硬件部分的电路原理、元器件选型采购与基础通信链路均已由我独立完成并跑通验证闭环（Demo 可稳定运行）。

为了将它们推向真正成熟、小型化并可量产落地的完整产品，我正在寻找对以下方向感兴趣的**软件算法合伙人**与 **PCB 硬件设计合伙人**：

### 🎯 期望的合作方向：

1. **ESP32 嵌入式固件与单片机开发**：
   * 深入理解并熟练使用 **ESP32 系列单片机**（熟练掌握 ESP-IDF 或 Arduino 开发框架）；
   * 熟悉 `ESP32-C3` / `ESP32-C6` (Wi-Fi 6 / Thread / BLE 5.3) / `ESP32-S3` 的外设驱动（I2C 多路复用、SPI、UART、DMA）；
   * 掌握低功耗电源管理、Wi-Fi / BLE 低延迟无线通信协议与 FreeRTOS 多任务并发调度。

2. **VR 动捕姿态解算与面捕算法**：
   * 熟悉 **SlimeVR / OpenVR / VRChat OSC** 等开源与元宇宙交互协议；
   * 掌握九轴 IMU 传感器融合姿态解算（如 Madgwick / 扩展卡尔曼滤波 EKF）及动态防漂移校准；
   * 熟悉基于红外摄像头的面部表情捕捉与眼动凝视追踪（VRCFaceTracking / Live2D / BlendShapes 映射）。

3. **PCB 硬件 Layout 与结构设计**：
   * 熟练使用立创 EDA (EasyEDA) / KiCad / Altium Designer 等 EDA 工具；
   * 能够根据已跑通的原型原理图与 BOM 选型，进行**超小型化高集成度 PCB Layout 画板**、射频天线匹配阻抗设计及电源完整性优化；
   * 具备 3D 结构堆叠、外壳结构设计（配合 3D 打印/开模）与可制造性设计 (DFM) 经验。

4. **嵌入式 UI 与跨平台上位机**：
   * 熟悉 **LVGL** 嵌入式图形界面开发（适配 ESP32 上的 TFT / OLED 交互）；
   * 熟悉桌面跨平台上位机开发（Python / Qt / Flutter / Web），能够编写美观的光谱曲线分析、色温/显色指数 (CRI) 计算与数据导出工具。
